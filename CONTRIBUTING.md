# Участие в проекте

Автор и единственный сопровождающий: **Кислов Роман Сергеевич** ([@rkislov](https://github.com/rkislov)).

Все могут открывать issues и присылать pull requests из своих форков. Прямые изменения в основной репозиторий, слияние PR, публикацию релизов и управление доступом выполняет только владелец. Права collaborator другим пользователям не выдаются.

Перед PR выполните на macOS:

```sh
go test -race ./...
go vet ./...
./scripts/build.sh
```

Для исправлений очистки добавляйте тесты с временными каталогами. Не используйте реальные пользовательские файлы в тестах. Не добавляйте автоматическую очистку, запросы sudo, сбор телеметрии или удаление без просмотра выбранных объектов.

Предложения и исправления принимаются под Apache-2.0. Эта лицензия разрешает создавать и изменять собственные копии и форки; ограничение записи относится к основному репозиторию, а не к правам на использование исходного кода.
